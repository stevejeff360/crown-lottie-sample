# YS Brands — GitHub Pages sample
One-page sample: the Crown Badge Lottie animation (Glaxnimate, adopted lane) playing on GitHub Pages.
- index.html — the page (lottie-web player via cdnjs, animation loops)
- crown-lottie-embedded.json — self-contained Lottie (crown image embedded, 981 KB)
- Push: create a PUBLIC repo, upload these files (keep .nojekyll), then Settings > Pages > deploy from main branch. Live at https://<username>.github.io/<repo>/
